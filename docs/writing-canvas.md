# Writing canvas (M17.2)

Markdown artifacts open with writing tools above the document.

- **Sections.** Headings (ATX and setext, not inside code fences) split the document. Text
  before the first heading is the Introduction; a document with no headings is one section.
- **Rewrite, Shorten, Expand.** Each acts on your selection, or on the chosen section. The
  request is an ordinary message, so it is routed, quality-floored, costed and logged like any
  other answer. The reply comes back as a proposal, shown as a diff against the version it
  started from. Nothing changes until you choose **Accept as new version**. Ask AI on a
  Markdown document works the same way.
- **Stale proposals.** If the document changed after the request, the proposal can be read
  and discarded but not accepted. Ask again from the latest version.
- **Replies during an edit.** A reply that started before you saved a newer version is kept
  as a proposal to review instead of overwriting your version.
- **Comments.** Select plain words (or pick a section) and comment. A comment stays pinned to
  its version. On a newer version it shows whether the passage moved (confirm the move) or is
  gone. Resolve and reopen as needed. Comments sync and export with the document; .docx and
  PDF exports don't include them.
- **Selections.** A selection is matched to the Markdown source only when it appears once and
  contains no formatting marks. Otherwise pick the section instead.
